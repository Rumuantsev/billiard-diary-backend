# Billiard Diary

Backend-сервис для дневника бильярдиста.

## Быстрый старт (для фронтенд-разработчика)

### Требования

- Node.js ≥ 18
- Docker + Docker Compose
- Git

---

### 1. Клонировать репозиторий

```bash
git clone <REPO_URL>
cd billiard-diary
docker compose up --build
```

### После запуска Backend доступен по адресу http:/localhost:3000
